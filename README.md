# SonicUnleashedPSV_Unity

A modern, open-source 3D fan project recreating the speed, spectacle, and mechanics of Sonic Unleashed in a custom/modern 3D engine  (Unity).

Overview
This project aims to faithfully reconstruct and modernise the Sonic Unleashed (2008) experience for PSVita


Key Features
 - Precise physics engine built from scratch to match Hedgehog Engine momentum and drift mechanics.
 - Boost gauge mechanics, drift turning, step-moves, quick-step, and wall-running.
 - Seamless 3D-to-2D side-scrolling camera transitions.
 - Runs at a smooth 30 FPS locked
   
Note: This is a non-profit fan project. All original assets, characters, sound effects, and music remain the intellectual property of SEGA and Sonic Team.
